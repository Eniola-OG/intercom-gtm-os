# Intercom GTM Context OS

A GTM Context OS for Intercom (https://www.intercom.com/), built as a public portfolio project from public information only. It holds ICP, positioning, messaging, brand kit, research, playbooks, learnings, meetings and campaign outputs, organised so Claude Code can read the right context before doing GTM work.

Start with `CLAUDE.md` for how the folder works and the rules. Each week's plan lives in `weekly-priorities/` and what changed lives in `work-log/`.

Secrets go in `.env` (git-ignored). CSV and XLSX exports are git-ignored too.
